# Охота за жетоном

Счётчик открытых сундуков в Fortnite (мини-сезон Treasure Hunters, ноябрь — 5 декабря 2026) с шансом найти пиратский жетон (Pirate Shop Access).

## Что умеет

- Кнопка +1 сундук, отмена последнего нажатия, +5 сразу.
- Клавиши: пробел или Enter — +1, Backspace — отменить.
- Отдельный счёт сундуков в Treasure Hour (суббота 19:00–21:00 UTC и воскресенье 02:00–04:00 UTC): режим «Авто» включает его по расписанию.
- Вероятность, что жетон уже выпадал хотя бы раз, и сколько сундуков осталось до шанса 50%.
- Таймеры до следующего Treasure Hour и до конца охоты.

## Шансы

По странице Treasure Hunt на [fortnite.gg](https://fortnite.gg/treasure-hunt): 1 из 137 500 на сундук, в Treasure Hour 1 из 91 667. Epic официально шансы не публиковала.

## Где хранится счёт

Открытая с GitHub Pages страница хранит счёт в браузере (localStorage): на другом устройстве или после очистки данных сайта он начнётся заново. Если открыть ту же страницу как Artifact в claude.ai, счёт сохраняется в аккаунте и синхронизируется между устройствами.

## Запуск

Это один файл `index.html` без сборки: откройте его в браузере или через GitHub Pages.
